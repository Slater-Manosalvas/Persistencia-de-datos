# Sistema de Gestión de Rally 

Proyecto desarrollado en Java utilizando JPA, Hibernate y MySQL para la gestión de vehículos de rally, pilotos, componentes, mantenimientos y carreras.


# Tecnologías Utilizadas

- Java
- Maven
- Hibernate
- JPA
- MySQL
- NetBeans
- Git y GitHub



# Funcionalidades

- Gestión de vehículos
- Gestión de componentes
- Gestión de mantenimientos
- Gestión de pilotos
- Gestión de carreras
- Relaciones ORM
- Consultas JPQL
- Persistencia de datos


# Relaciones Implementadas

- OneToMany
- ManyToOne
- OneToOne
- ManyToMany



# Consultas JPQL

El proyecto implementa:

- Filtros
- Ordenamiento
- Paginación
